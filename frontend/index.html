¿Qué está calculando el modelo?

Una red LSTM combina la demanda histórica, el clima, el precio y el calendario para estimar la demanda eléctrica de la siguiente hora.

¿Basta con ingresar el clima previsto?

Este modelo necesita las últimas 24 horas observadas, incluida su demanda eléctrica. Las variables de calendario se generan a partir de la fecha.

Para predecir solo con la hora futura y el clima previsto, se necesita un modelo entrenado con esas entradas. El precio debe conservar la unidad y escala originales.
